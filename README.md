# La Veille

Veille quotidienne en pédagogie et sciences de l'apprentissage, pour un ingénieur pédagogique.

- **Application** : https://maaxxxnrg.github.io/veille-pedagogique/
- **Données** : `veille.json` (publications, avec résumé, version vulgarisée et traduction préparés à l'avance) et `sources.json` (sources suivies).
- **Mise à jour** : une tâche planifiée Claude ajoute chaque vendredi, avant 6h (heure de Paris), les publications de la semaine écoulée dans `veille.json`.
- La bibliothèque, le thème et les sources ajoutées avec « + » sont gardés dans le navigateur, sans compte.
